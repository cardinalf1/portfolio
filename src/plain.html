Personal builds

Blackbook

Offline Digital SAT practice simulator. Status: Released, v1.0.0. About 3,700 questions, 241 recorded changes.

A desktop app, with installers for Windows and Mac, that recreates the real Digital SAT test screen on your own computer.

  • Test room with timer, question navigator, formula sheet, line reader, answer eliminator, highlighter and a built-in Desmos graphing calculator
  • Full-length adaptive tests where the second half responds to the first, targeted practice by skill and difficulty, and a 20-question quick mode
  • Mistake notebook that sorts errors into categories
  • Analytics: accuracy by skill, time per question and projected score ranges
  • Optional AI explanations and coaching, using the student's own free Groq key
  • Backup and sharing of the question bank

AI: Optional. The AI only chooses and words things from numbers that ordinary code already worked out. It never touches the timer or the scoring, and the app works fully without it.

No accounts and no tracking, and a written list of the only four things that ever use the internet. It ships no copyrighted questions: each user downloads the public question bank to their own computer. Limits: desktop only, and it relies on that public bank staying available.

Takt

Voice dictation that works in every application. Status: Released, with installer. 0.6 to 1.1 s from key release to text.

Hold a key, talk, release, and clean written text is typed into whichever app is in front of you. It runs on Windows and on Linux (Wayland and Hyprland, which my own computer uses).

  • Push-to-talk, or a toggle mode
  • Removes filler words such as "um" and "uh" and understands the spoken command "scratch that"
  • Formats text to suit the app: code, chat or ordinary writing
  • Removes background noise before turning speech into text
  • Optional Privacy Shield that hides secret keys and card numbers before text is inserted
  • Short phrases never leave the computer. Online clean-up is optional and used only for long, rambling speech

AI: It is the core of the product. Speech, noise removal, filler-word and sensitive-data models all run on your own computer. The speech and noise models come from other people (Whisper and Desert Ant Labs). I built the application around them.

The microphone opens only while the key is held, and nothing leaves the computer by default. Limits: no Mac version, and a heavier install (about 670 MB to download on Windows) because the models are inside.

relay

Your home computer, from anywhere. Status: Done. Starts a powered-off PC, then runs whatever you email it.

From any web browser, even a locked-down school computer, enter a password and my home computer switches on, the disk password is typed in automatically, and the desktop streams to you.

  • An ESP32-S3 chip stays on at home. It sends the wake signal, presses the power button through a small circuit, and acts as a USB keyboard to type the disk password
  • Login uses a one-time challenge, so the password is never sent over the internet
  • A private network link gets past my internet provider's shared addresses, and a game-streaming tool shows the desktop
  • Email bot: send an email and a Claude conductor can wake the computer, run coding agents, run jobs and email back a report

AI: The email bot is an AI agent with written limits: allowed senders only, checks against forged addresses (SPF and DKIM), attachments treated as untrusted data, and a cap on messages. I built it with Claude Code and handoff documents.

It gets around real obstacles: shared internet addresses and an encrypted disk. Limits: complicated to set up, and stream quality depends on home upload speed.

Scrub

Handheld music player with a haptic wheel. Status: Designed, not yet built. 4-layer board, 100 x 86 mm. 39 recorded changes.

A handheld lossless music player and macro deck, designed from scratch as a circuit board. The wheel is driven by a motor, so it can give you adjustable clicks. This one is hardware.

  • Lossless FLAC playback up to 24-bit from a memory card, through a 32-bit DAC and headphone amplifier to a 3.5 mm socket
  • Bluetooth output through a second dedicated chip
  • Haptic scroll wheel: a brushless motor with a magnetic angle sensor
  • 3.5-inch colour display, USB-C charging with battery protection, and a macro deck mode over USB
  • In the project folder: a routed four-layer board that passes the design-rule checks, JLCPCB manufacturing files, 3D case models, firmware with a simulator, a cost estimate for India, a ranked risk list and a staged bench-test plan

AI: Used only to design it, never inside the device. A written team of models with Claude Opus as manager and free models for reading datasheets and first drafts. A PROVENANCE.md file records which decisions were mine and which work was done by which model.

Not built, not ordered and not powered on. The firmware has never run on real hardware. My own risk list ranks this first: a first-time four-layer board routed with scripts. Finishing it is my next test.

Public home of the STEM Racing team. Status: Published, Jun 2026. Deployed automatically to GitHub Pages.

A single-page public site that presents the team to visitors and sponsors. It deploys automatically to GitHub Pages.

Overture

The team's management portal. Status: Built. Built 6 Jul to 30 Aug 2026.

A private web app for running the whole team: schedule, engineering work, budget and sponsors in one place. It began as a Google AI Studio template and grew into a custom system with a 12-section capabilities document.

  • Command Center: tasks with owners, status and dependencies beside a hand-drawn SVG Gantt chart with planned and actual bars and a today line
  • Engineering hub: every version of every car part, with an interactive 3D viewer, weight change and a status from Draft to Milled or Rejected
  • Sponsor portal: every item the team must buy, the amount pledged, the gap and a progress bar. Sponsors can log in and pledge an item
  • Access control: four roles, three department roles and a greenlight switch, so a correct password without approval is signed out
  • Works offline from browser storage, or syncs to a database with live updates for everyone

AI: A chat assistant that could create and update tasks was started, then switched off by the administrator, and the screen says so. It is a planned feature, not a working one. The security rules were written by a person, not left to a model.

The best-documented project I have. Limits: the sponsor portal is over 1,300 lines in one file and would be hard to maintain, and password handling for custom sessions should be reviewed by a security expert before the app holds sensitive data.
